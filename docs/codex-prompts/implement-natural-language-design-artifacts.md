# Implement maintained engineering artifacts in Natural Language Design

Execute the recommendation in `docs/investigations/design-management-artifact-generation-review.md`, targeted specifically at **Design Management → Natural Language Design**. Implement the core capability, not another review. Keep Reports and the SysML modeler UI unchanged, preserve existing uncommitted work, and do not call a live provider, use personal workspace data, deploy or commit.

Implement the foundational storage/identity fixes and a working end-to-end artifact workflow covering ConOps, system specifications, subsystem specifications, system/subsystem design documents and interface specifications. Use versioned templates and one generation service; additional architecture/verification/validation templates may use the same infrastructure. A user must explicitly select program/project ownership, system/subsystem/interface scope, destination folder and source modules/notes. Do not conflate a design folder ID with an engineering project ID or silently collect other projects' evidence.

Generated artifacts belong as typed modules in the existing Natural Language Design folder/module browser. Provide editable object/section hierarchy and Outline, Table, Document and Trace presentations of the same canonical objects. Add a polished document preview, source references, missing-input states, persisted proposals, review/acceptance, revision comparison, baselines and structured portable exports. Do not put large bodies in localStorage or maintain a second Markdown authority.

Use a named IndexedDB repository with atomic revision publication, compact metadata, optimistic concurrency checks and immutable revisions; integrate backup and project cleanup. Reuse existing configured AI backend routing, validate bounded structured responses, implement cancellation and recoverable per-section checkpoints, and separate draft generation from acceptance. Preserve accepted/manual objects during regeneration; require explicit conflict resolution when a base revision changes. Never invent verification outcomes, approvals, interface contracts or source references.

Maintain artifacts using complete selected-source manifests and semantic hashes, automatic stale/unavailable detection while the view is closed, and startup catch-up. Default maintenance must not call AI or rewrite content. Regeneration produces reviewable proposals, preserving manual changes and stable IDs. Prevent loops, cross-scope writes, stale result application and resurrection after deletion. Keep expensive work bounded and the interface responsive.

Repair the existing shared module population path's identity/hierarchy/content/provenance loss and the mounted provider's separately generated return IDs. Use ID-based mutation boundaries and honest persistent-save failures. Preserve compatibility for existing hand-authored modules and avoid a destructive legacy migration.

Add meaningful synthetic regression tests for repository atomicity/concurrency, ownership, generated-response validation, >120-row source coverage, missing/unreadable/changed sources, cancellation/partial drafts/resume, manual edits and stale proposals, maintenance while the editor is closed, baseline/export/reload, and UI generation/review/editing. Run focused/adjacent tests, lint changed files and a production build; investigate failures. Record implementation, verification and explicit limitations in `docs/investigations/natural-language-design-artifacts-implementation.md`. Complete a useful integrated feature rather than leaving disconnected services or a cosmetic preview.
