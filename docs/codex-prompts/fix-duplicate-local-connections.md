# Prevent accidental duplicate local connections

Trace local-folder selection, verification, save and analysis. Keep existing source and repository IDs when reconnecting an existing folder, including before analysis storage keys are chosen. Browsers do not reliably expose absolute folder identity: never merge connections merely because their names match. When a newly selected folder shares a saved connection name, require a choice to reuse that connection or intentionally add a separate source. Preserve saved analysis and do not deduplicate existing records destructively. Provide an explicit way to remove an inactive unused connection without deleting stored results. Test repeated selection, separate same-name folders, cancelled/unresolved selection, and reused analysis scope. Run related tests and syntax checks.
