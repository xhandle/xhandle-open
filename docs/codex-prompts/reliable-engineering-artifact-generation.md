# Review and implement reliable engineering artifact generation

Work in Design Management → Natural Language Design. Review the current artifact-content generation implementation and implement a coherent solution for single artifacts and complete systems engineering projects. Execute this prompt in the current checkout; preserve unrelated uncommitted work and the existing Outline, Table, Document and Trace workflows.

Trace source capture, request construction, provider routing, response parsing, validation, citation mapping, section checkpoints, project dependencies, cancellation, navigation and final acceptance. Explain the causes of the repeated citation, truncation and section-format failures. Look beyond these messages for transport failures, oversized requests, lost partial work, accidental cancellation, stale responses and completion states that could be misleading.

Implement bounded, deterministic recovery: classify failures; retry transient transport failures with cancellation-aware backoff; keep permanent errors actionable; split repeatedly failing work into smaller persisted units where appropriate; retain exact source identities and stable object identities; resume completed work without regeneration; and allow navigation without implicitly canceling an active run. Preserve deliberate Pause, immutable accepted revisions, manual edits, source-change checks and cross-tab conflict protection. Complete generation only when every required section is valid and saved. Never declare success by dropping sections, inventing sources, fabricating evidence gaps to conceal a provider failure, or accepting partial/truncated responses. Preserve explicit uncertainty for engineering claims unsupported by evidence.

Review prompt/content contracts for each artifact type. Keep source text untrusted, preserve ownership and diagram/element provenance, and keep user-facing progress/errors readable. Do not introduce an unbounded retry loop or promise completion during provider outage, missing credentials, changed sources, storage failure or user cancellation. Handle these cases with an honest resumable state.

Write findings and the implemented design to docs/investigations/reliable-engineering-artifact-generation.md. Add fault-injection tests covering combined response/transport failures, repeated failures, retry exhaustion, cancel/backoff, checkpoint/reload recovery, navigation, concurrent runs, multi-document completion, source identity and publication invariants. Run appropriate regression suites, lint and production build, then exercise the production browser using disposable synthetic data. Do not use personal browser data, call a live paid provider, commit or deploy. Report what changed, verification and remaining operational limitations.
