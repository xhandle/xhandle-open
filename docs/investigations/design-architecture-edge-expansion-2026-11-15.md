# Architecture edge aggregation in Design Management

Imported code diagrams previously enabled directional bundling by default. The shared canvas also allowed directional and bidirectional bundling simultaneously, so expanding one mode could leave the other grouping active. The code adapter already retains original relationships at the selected abstraction's endpoints; source evidence does not need to be rewritten to restore those edges.

New artifact canvases start with individual relationships, independently of the owning project's saved bundling preferences. Artifact-specific saved preferences continue to overlay the private canvas storage. Code and functional artifact canvases request mutually exclusive aggregation controls: changing modes clears the other mode's global and selected-pair preferences, and disabling an active mode restores the original relationships. Existing artifact layouts with both global modes enabled can be expanded with either active global control. Projects retain their existing independent controls.

The fix preserves source snapshots, relationship IDs, selected abstraction, grouping, routing, comments, manual arrangement and artifact-specific persistence. Explicitly resetting an artifact's aggregation preference also restores individual edges. Coarse views count the original relationships when deciding whether to page; a small number of bundles containing more than 1,000 relationships no longer bypasses the existing view limits. These pages retain projected endpoints and aggregate evidence identities for inspection and focus navigation.
