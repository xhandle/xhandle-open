# Higher-level Functional capabilities

Functional model version 3 groups cohesive implementation steps at the architecture-component level rather than restricting consolidation to one file. The consolidation prompt asks for end-to-end capabilities instead of methods, helpers and calculations. Batches now include up to 32 candidate responsibilities. Requests remain bounded to four concurrent workers. Unallocated components retain file separation; missing allocation cannot justify merging unrelated files.

Distinct control, feedback and unresolved boundaries remain protected. Every original relationship remains mapped to a capability's internal evidence or an external interaction. Multi-file capabilities carry all file evidence without claiming one arbitrary file as their owner. Hazard input, table and CSV use the same derived model.

Functional layout places responsibility nodes directly under their component. It omits CSU wrappers, their padding and duplicate node subtitles. Detailed CSU rendering retains its containers. Functional uses a versioned layout key so old low-level positions are not applied to the new hierarchy.

Existing version-2 models require regeneration; source extraction does not need to be repeated. This intentionally invalidates previous functional model readiness and dependent functional hazard snapshots without overwriting existing hazard runs.

Validation: 33 regression suites / 256 tests passed; final processing tests also cover old-model regeneration. An eight-step, eight-file synthetic fixture consolidates to one capability, one internal evidence row and one external interaction while retaining all eight source references. Protected boundaries cannot be absorbed. Isolated Chromium verifies no Functional CSU wrappers, retained detailed CSU wrappers, nonoverlap, source navigation, persistence, local/GitHub parity and hazard integration. Build and lint checked. No paid model request or customer dataset was used; actual row reduction depends on semantic cohesion and unresolved boundaries, not a forced node-count target.
