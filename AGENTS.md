# Public source privacy

This is a public source repository. Never commit personal financial records, private organization identities, incident reports, account/profile exports, credentials, personal workspaces or generated local output. Keep those outside tracked source. The `output/` directory is intentionally ignored.

Use anonymous, deliberately synthetic fixtures and generic labels in source, tests, screenshots, prompts, documentation, PR descriptions and release notes. Public validation records should describe implementation behavior and synthetic benchmark results without reproducing private incident telemetry or account/campaign history. Review all staged files and new documentation for this before committing or pushing.

Preserve existing unrelated edits. Shared application code belongs here; Electron/native code and signing/release receipts belong in the private desktop repository. Validate the exact cumulative source and destination-OS packages before promoting public update feeds.
